## 🗂️ Structure du projet

Le programme est organisé par thématiques. Consultez le [SOMMAIRE.md](SOMMAIRE.md) pour une vue d'ensemble.

```
2027/
├── economie/          # Croissance, innovation, compétitivité
├── emploi/            # Marché du travail, formation professionnelle
├── education/         # École, université, recherche
├── sante/             # Système de santé, hôpitaux
├── environnement/     # Transition écologique, climat, énergie
├── securite/          # Police, prévention
├── justice/           # Système judiciaire
├── international/     # Diplomatie, Europe
├── institutions/      # Réforme démocratique
├── social/            # Protection sociale, retraites
├── culture/           # Arts, patrimoine, médias
├── agriculture/       # Monde rural, souveraineté alimentaire
├── defense/           # Armées, dissuasion
├── immigration/       # Politique migratoire
├── logement/          # Accès au logement
└── fiscalite/         # Impôts, redistribution
```

Chaque dossier contient un fichier `programme.md` avec :
- **Contexte** : État des lieux de la situation actuelle
- **Propositions** : Mesures concrètes
- **Financement** : Chiffrage et sources de financement
- **Calendrier** : Plan de mise en œuvre

## 💡 Comment contribuer

Nous accueillons toutes les contributions ! Voici plusieurs façons de participer :

### 🐛 Ouvrir une issue

Si vous avez une idée, une question, ou repérez un problème :

1. Allez dans l'onglet [Issues](../../issues)
2. Cliquez sur **New Issue**
3. Choisissez un titre clair (ex: "Proposition : Réforme de l'ISF" ou "Question : Financement de la santé")
4. Décrivez votre idée ou problème de manière détaillée
5. Ajoutez des labels pertinents si possible

### 📝 Soumettre une Pull Request

Pour contribuer directement au contenu :

#### 1️⃣ Forker le projet
Cliquez sur le bouton **Fork** en haut à droite de cette page pour créer votre propre copie.

#### 2️⃣ Cloner votre fork
```bash
git clone https://github.com/VOTRE_USERNAME/2027.git
cd 2027
```

#### 3️⃣ Créer une branche
```bash
git checkout -b proposition/nom-descriptif
# Exemples de noms :
# - proposition/reforme-retraites
# - ajout/financement-sante
# - correction/typo-education
```

#### 4️⃣ Faire vos modifications
- Éditez les fichiers markdown dans le(s) dossier(s) concerné(s)
- Respectez la structure existante (Contexte, Propositions, Financement, Calendrier)
- Soyez factuel et sourcez vos affirmations quand possible

#### 5️⃣ Committer vos changements
```bash
git add .
git commit -m "Ajout : proposition sur [thème]"
# Exemples de messages :
# - "Ajout : mesures pour l'emploi des jeunes"
# - "Amélioration : section financement de la santé"
# - "Correction : typos dans environnement"
```

#### 6️⃣ Pousser vers GitHub
```bash
git push origin nom-de-votre-branche
```

#### 7️⃣ Créer la Pull Request
1. Rendez-vous sur votre fork sur GitHub
2. Cliquez sur **Compare & pull request**
3. Décrivez vos modifications de manière claire
4. Ajoutez le contexte et les raisons de vos propositions
5. Soumettez la PR pour revue

#### 8️⃣ Revue et discussion
- Les mainteneurs et la communauté reviendront vers vous
- Soyez ouvert aux discussions et aux modifications
- Une fois approuvée, votre contribution sera mergée !

## 🤝 Code de conduite

Ce projet vise à rassembler des personnes de tous horizons politiques. Nous attendons de chaque contributeur :
- **Respect** : Traitez les autres avec courtoisie, même en cas de désaccord
- **Constructivité** : Proposez des alternatives plutôt que de simplement critiquer
- **Transparence** : Sourcez vos affirmations et soyez honnête sur les limites
- **Ouverture** : Acceptez que d'autres puissent avoir des opinions différentes
